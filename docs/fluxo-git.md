# Fluxo Git do projeto

## Branch principal

A `main` e a branch estavel. Trabalhos novos devem sair de uma branch criada a partir dela.

## Branches de trabalho

Exemplos:

```text
feature/ifr-basico
feature/media-movel-alerta
fix/parametros-entrada
docs/primeiro-uso
```

## Commits

Prefira commits pequenos, com mensagens no imperativo:

```text
Cria estrutura inicial do indicador IFR
Ajusta calculo do buffer principal
Documenta parametros de entrada
```

## Pull Requests

Um bom Pull Request explica:

- O que foi alterado.
- Como compilar e testar.
- Se ha impacto em indicadores existentes.
